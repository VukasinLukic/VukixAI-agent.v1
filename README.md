# Local AI Coding Agent

A fully local AI coding agent for generating, analyzing, and modifying code without relying on cloud AI services or API costs.

---

##  Tech Stack

*   **Ollama** — Local LLM runtime
*   **Qwen2.5-Coder 7B** — Primary coding model
*   **DeepSeek Coder 6.7B** — Code analysis and reasoning
*   **claw-code** — Agent framework

---

##  Features

*   **Code Generation** — Generate and modify code locally.
*   **Repository Analysis** — Analyze existing codebases and repositories.
*   **Smart Debugging** — Assist with bug tracking and development.
*   **Privacy-First** — Run AI models without cloud APIs or data leaks.
*   **Flexible Workflows** — Experiment with custom local AI agent configurations.

---
