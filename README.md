Local AI Coding Agent

A fully local AI coding agent for generating, analyzing, and modifying code without relying on cloud AI services or API costs.

Tech Stack
Ollama — local LLM runtime
Qwen2.5-Coder 7B — primary coding model
DeepSeek Coder 6.7B — code analysis and reasoning
claw-code — agent framework
Features
Generate and modify code locally
Analyze existing repositories
Assist with debugging and development
Run AI models without cloud APIs
Experiment with local AI agent workflows
